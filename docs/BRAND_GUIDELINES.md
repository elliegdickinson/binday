# Bin Day — Brand Guidelines

## Brand
**Name:** Bin Day  
**Primary line:** **Your bins. Your calendar. Sorted.**  
**Product promise:** Never wonder which bin it is again.

Bin Day makes a boring life-admin problem feel weirdly satisfying. The experience should feel like a public utility somebody actually cared about designing.

## Personality
- Useful first, fun second.
- Clear, chunky, accessible and slightly playful.
- Friendly, never childish.
- Dry British humour rather than puns.
- Confident and direct, never corporate.
- Avoid generic SaaS gradients, glassmorphism, excessive pills, and “startup cute”.

## Typography
### Display
Use **Space Grotesk** in **Bold / ExtraBold (700–800)** for:
- Hero headlines
- Section headings
- Large promotional messages

Headlines should be oversized, tightly spaced, and high contrast.

### UI / Body
Use **Atkinson Hyperlegible** in **Regular / Bold (400 / 700)** for:
- Body copy
- Forms
- Navigation
- Buttons
- Labels
- Helper text
- Error messages

Fallback: `Arial, Helvetica, sans-serif`

### Recommended scale
- Desktop hero: 64–96px
- Mobile hero: ~48px
- H2: 36–56px
- H3: 28px
- Body: 16–18px
- Small/helper: 14px minimum

Do **not** substitute rounded bubbly fonts.

## Colours
### Core
- Bin Day Green — `#C8FF38`
- Electric Blue — `#456CFF`
- Cream — `#F7F4EA`
- Ink — `#161616`
- White — `#FFFFFF`
- Mid Grey — `#6B6B6B`

### Bin categories
- General waste — `#454545`
- Recycling — `#456CFF`
- Garden waste — `#4B9E39`
- Food waste — `#FF7A2F`
- Paper / card — `#A23CF0`

Never rely on category colour alone. Always pair with an icon and a written label.

## Layout
- Mobile-first.
- Strong whitespace.
- Large type.
- Simple cards.
- 12–16px default corner radius.
- 48px minimum interactive control height.
- Keep pages visually calm.
- One primary action per screen.

## Logo
Primary logo: stacked **BIN / DAY** wordmark with wheelie-bin mark.

Use the black + Bin Day Green version on Cream or White wherever possible.

Do not:
- add gradients
- distort the logo
- recolour it randomly
- place it over visually busy photography
- add drop shadows
- redraw it as a cute mascot

## Voice
Good:
- “What bin is it this week?”
- “No account. No faff.”
- “Here’s what’s going out.”
- “Never think about bin day again.”
- “That’s the bins sorted.”
- “You may now return to more interesting things.”

Avoid:
- “Wheely good news!”
- “Bincredible!”
- excessive emojis
- jokey copy on errors or important service messages
- council jargon like “refuse collection schedule”

## Core UX flow
1. Enter postcode
2. Select address if needed
3. Show next collections
4. Add collections to calendar
5. Confirm success

The user should not need to create an account or know their council.

## Accessibility
Target WCAG 2.2 AA.
- Minimum 4.5:1 contrast for normal text.
- Visible keyboard focus.
- Semantic HTML.
- Proper form labels.
- 44×44px minimum pointer target; prefer 48px controls.
- Never encode information with colour alone.
- Keep body copy at least 16px.
- Respect reduced motion.
- Avoid unnecessary animation.
- Plain-English error messages.

## Design anti-patterns
Do not turn Bin Day into:
- a sustainability startup
- a municipal council portal
- a bubbly children’s app
- a generic blue SaaS dashboard

The visual target is closer to:
**modern public-information design + bold independent consumer brand.**
